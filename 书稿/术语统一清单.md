# 全书术语统一清单

## 统一用词

| 用词 | 含义与使用范围 |
| --- | --- |
| 上级 | 组织中的上下级关系。经营者及“老板心态”中的“老板”保留。 |
| 导师 | 指导新人、实习生或提供职业成长指导的人。 |
| 负责人 | 对项目、模块或某项工作负责的人，不等同于上级。 |
| 同事 | 职场中的共事人员；学校场景仍用“同学”。 |
| bug | 软件缺陷；服务异常或事故表现仍可称“故障”。 |
| web | 网页及相关开发场景，使用小写。 |
| 完成线 | 一项任务做到什么程度才算完成；岗位基本能力门槛仍称“及格线”。 |
| 薪酬 | 工作提供的整体报酬。具体月工资仍用“工资”；企业经营、副业等收益用“收入”。 |
| 需求单 | 记录产品需求的材料。 |
| 晋升 | 职级或职位的提升；“升职加薪”等自然搭配保留。 |

## 其他固定写法

- 英文名称：APP、MVP、OKR、PUA、Python、Word、TikTok、hotfix、offer。
- 工作角色与流程：直属上级、隔级上级、产品经理、人天、代码评审、需求评审。
- 书中概念：老板心态、分而治之、知识债务、抉择点、注意力专区、内耗式努力、第二曲线、零基思维。
- 中文与英文词之间留空格。

## 含义区分

- **工作量与工期**：工作量用“人天”；工期用“天”或“工作日”，不把“5 天的人力”当作工期。
- **复盘与回顾**：复盘包含对过程、判断和改进的分析；回顾可以只表示回想过去的事情。
- **自测与自查**：自测指按用例测试；自查还包括文档、埋点等更广的核对。
- **精力与能量**：精力是本书讨论的概念，能量可用于解释其含义。
- **正式名称与简称**：时间四象限可在上下文明确时简称“四象限”；番茄工作法指方法，番茄钟可指采用该方法的计时工具或专注时段。
