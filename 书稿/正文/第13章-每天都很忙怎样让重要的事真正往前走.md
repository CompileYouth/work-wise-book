# 第13章　时间管理：每天都很忙，怎样让重要的事有进展

每天从早忙到晚，消息回不完，会议一个接一个，下班的时候人挺累，心里还觉得挺充实。可到了月底，或者写总结的时候，却说不出这段时间做成了什么：该学的东西没开始学，该提前准备的材料一个字没动笔，要紧的项目还停在原地。

这种状态，不能怪人不努力。毕竟一天没闲着，怎么能算不努力？问题在于，这一天做了哪些事，往往不是自己安排的：时间被各种找上门的事情填满，自己想推进的事反而总是轮不到。绩效和成长看的都是做成了什么，不是忙了多少；而时间这东西，自己不安排，别人就会来安排。

## 1. 一周忙下来，时间都花到哪里去了？

有一阵子，我负责的 MVP 模块陆续进入提测阶段，节奏比项目初期宽松了不少，手头剩下的事不多，也不紧急，在人人都忙的团队里，我成了少有的例外。既然有了空闲，我就主动找事支援。我先告诉上级我这边有空余时间，他正发愁一个技术预研没人做，顺势交给了我；又看到团队里一位同事在赶周五截止的需求，测试同事还追着他提上个版本遗留的问题，看他压力不小，我提出帮他修手上紧急的 bug。

结果有些出乎意料。他不只把手上两个紧急的 bug 转交给了我，后面测试同事再反馈新 bug，他也不打招呼，直接转交了过来。那两天我一直在修 bug，到了周五回想这一周：很忙，忙得挺充实，可要说做成了什么，说不出来。上级交给我的预研，反倒被这些 bug 挤到了后面。

先要说清楚，主动支援这件事本身没错，同事的需求赶上了截止日期，我的帮忙是实打实的。错在两个地方。一是帮忙没约定范围：我说的是帮他修“手上紧急的”，做着做着，新反馈的 bug 也一个不落全到了我手上。提供帮助时本该谈清下一步该谁做，我恰恰没有这么做。二是自己手头重要的事没有先安排：预研才是这一周该往前推的事，我却没有给它留出固定的时间，空出来的时间就这么被一件件转来的 bug 占满了。

忙碌本身就带着充实感。一整天不停地回消息、处理问题，下班时不觉得虚度，甚至还有点成就感。可成果是另一回事，看的是周报里写得出什么，月底能说出哪件事靠自己往前走了一步。这两样经常对不上：那一周我的消息记录密密麻麻，能写进周报的却没有几行。

时间不只会被别人的事占用，也会从自己手里溜走。不少人到公司后的头三件事是倒杯水、刷一遍工作群、随手点开几个网页，一晃小半天就过去了。一边任由空余时间这样溜走，一边抱怨琐事太多、没时间干正事，这两件事经常发生在同一个人身上。

所以隔一段时间，就该盘点一次时间的去向。回顾一周，时间花在了哪几类事情上，哪些事留下了拿得出手的成果，哪些只留下了“忙过”的感觉。不用精确到小时，能说出个大概就够。要是连着几天说不出成果，就说明该动手调整了，而调整的第一步，是看清时间到底花在了哪里。

## 2. “假努力”：做的事和真正的目标有关吗？

时间被琐事占满，问题看得见。还有一种问题不容易发现：做的事看起来很正经，投入也是真的，却和目标对不上。

小 F 给自己立了个目标：每天早上六点起床，晨读一小时英语。坚持了一段时间，人越来越疲惫，英语却没见什么长进。问题出在哪里？他把“早起晨读”这件事本身当成了目标。每天挣扎着爬起来，稀里糊涂读满一小时，任务就算完成，至于读进去了多少，没人管，他自己也不问。

其实多问一层就清楚了。他为什么早起？因为上班忙，白天没有整块的学习时间。为什么学英语？因为想出国工作。这样一路问下来，目标应该定成“一年内通过英语考试，拿到能出国工作的 offer”。目标一清楚，判断的标准就有了：读什么材料对考试有用，现在的读法有没有效果，进度跟不跟得上，是不是一定要早起一小时，能不能改成趁吃饭、午休的时间学。这些问题有了答案，睡眠有了保障，目标也能达成。

工作里类似的事不少见。报名的课程学了个开头就搁下了，收藏的文章再没打开过，会议全都参加了、笔记记了一堆，从没翻过第二遍。这些事都做了，时间也真花了，可并没有因此离目标更近。帮同事修 bug 也一样：帮忙本身没错，可要是自己的正事因此停摆，这份投入就该重新掂量。

所以对那些反复投入时间的事，值得问一句：它服务于哪个目标？答得上来又确实要紧的，继续做；答得上来但眼下不急的，往后放；答不上来的，干脆放下。这一圈问下来，手里会多出一份清单：哪些要做，哪些推迟，哪些放弃。

有一点要说清楚：这个判断针对的是事，不是给人贴标签。答不上来，不代表这个人不努力；忙碌的程度，也说明不了一个人的价值。方向不清的时候，投入再多也换不来踏实，这正是要停下来问一句的原因。

## 3. 时间四象限：重要和紧急，怎样分先后？

目标清楚了，要做的事还是一大堆，先做哪件？可以从两个角度看手头的每件事：重要不重要，紧急不紧急。按这两个角度划分，所有的事分成四类，就是常说的时间四象限。

重要又紧急的事，比如明天就要提交的晋升答辩材料、疼得厉害的蛀牙，毫无疑问排在最前面。不过可以多问一句：紧急是怎么来的？答辩的日子早就定了，牙齿也不是一天两天才坏的，拖着拖着，重要不紧急的事就变成了非做不可的急事。很多急事不是一开始就这么紧急，是从“重要但不紧急”那一类拖过来的。

重要但不紧急的事，比如下个月答辩的材料、刚有点症状的牙齿。它们不催人，今天不做也不会出事，可日后拉开差距的恰恰是这一类：能力的积累、身体的状况、要紧项目的提前准备，全在这里。这类事往后拖，要么拖成急事，要么就此荒废。

紧急但不重要的事，比如话费停机要充值、临时被拉去旁听一个会议。它们催促得厉害，做起来也不难，可对自己的目标没什么贡献，占用的却是同样的时间。这类事越少越好：能拒绝就拒绝；拒绝不了的，想办法让它少占用时间，比如给话费开通自动充值，不需要自己发言和决策的会议不去，会后看纪要就行。

不重要也不紧急的事，比如打一局手机游戏、刷一会儿短视频。拿来当休息的调剂没问题，别让它占去整块的时间。

四象限安排的是自己的优先级，但有一条界线：跟上级、协作方约定过的交付，是团队的排期，不能自己觉得“不重要”就单方面延后。自己的判断和团队的安排有冲突，就把想法拿出来协商，谈成什么样，就按什么样执行。

另外，重要不重要，标准在自己的长期目标，不在有没有人催促。同样一件事，对别人是可有可无的杂事，对自己可能是要紧的积累。判断之前，先回到自己的目标上。

## 4. 每日三件事：给长期目标安排今天的行动

重要但不紧急的事，有的没有明确期限，有的期限还远，眼前没有人催，很容易想着“明天再说”。今天不准备答辩的材料，没关系；明天不准备，也没关系；可两个月过去都没准备，关系就大了。

我对付它的办法，是一个叫“每日三件事”的习惯：每天早上，给自己定下三件当天要做的事，其中有意识地放进长期目标拆分出来的一小步。长期的事往往太大，让人无从下手，那就拆分成一天能做完的小事。比如两个月后要晋升答辩，今天的一件事可以是“把上半年做过的项目列成清单”；想系统掌握一门技术，今天的一件事就是“读完官方教程的第一章并跟着练习”。

这个办法起作用的关键，在于三件事是早上定下的。定下之后，一有空闲，人会有意识地先去做它们；琐事照样会来，但重要的事不再永远排在“等有空”的最后。同样是一段空余时间，事先没有安排，就会被别人的事一件件占掉；早上先放进自己的三件事，到周五回头看，成果就完全不同。

三件事也不是定下来就一劳永逸，得隔一段时间检查一遍。总是完不成，多半是一件事拆分得太大，或者一天安排得太满；做是做完了，回头一看总跟目标不相干，那就回到前面那个问题，把“这件事服务于哪个目标”重新核对一遍。目标变了、工作的节奏变了，三件事的内容也跟着变。记录的工具不讲究，手机的备忘录就够用，关键是随时看得到。

还是那条界线：三件事是给自己的，不替代团队的排期，答应过别人的交付照旧。它管的是那些没人催、只能靠自己推进的事。

每天都很忙，忙本身不是问题，忙完说不出成果才是。往后再遇到从早忙到晚的一天，睡前可以问一句：今天的三件事，做完了几件？要是连着几天答不上来，就该找个时间，把时间的去向盘点一遍了。
