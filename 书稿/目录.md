# 专业之外：从学生到职业人的 21 堂成长课

> 目录修订稿
>
> 面向工作 0—5 年的职场人，围绕五个问题展开：如何理解职场与自己的角色，如何把事情做成，如何与人合作相处，如何管理自己，以及如何积累能力、经营职业发展。

## 序言｜毕业之后，还要重新学习什么

- 为什么认真、努力、成绩好，仍可能在工作中感到无措
- 从一次次具体的工作经历中，练习职业人的判断和行动
- 如何使用这本书：顺着成长路径读，也可以带着手头的问题读

## 第一篇｜看懂职场：从学生到职业人

### 第1章　角色转变：从学生到职场人，哪些做事习惯要改变

1. 把自己的事做完，还不够吗？
2. 什么都自己来，才算有能力吗？
3. 开口请教之前，自己的功课做好了吗？
4. 上级会像老师一样带着我吗？
5. 上级会安排工作，成长要自己安排

### 第2章　入职适应：进入新团队，别等着有人来带

1. 公司、部门、团队：弄清自己在什么位置
2. 第一次与上级沟通，该问清什么？
3. 第一次与导师沟通，该了解什么？
4. 从一起吃饭开始，认识身边的同事
5. 没人带，怎样自己熟悉工作？

### 第3章　老板心态：看懂工作的价值

1. 事情做了，目的就达到了吗？
2. 把工作当作服务：为谁做，解决什么问题？
3. 工作 sense：从业务目标看懂任务的轻重
4. 对结果负责，也要懂得时间、成本与质量的取舍
5. 主动改进，先看工作真正需要什么

## 第二篇｜把事做成：从接到任务到完成交付

### 第4章　任务确认：动手之前，把“做成什么样”说清楚

1. 任务听懂了，为什么还要复述一遍？
2. 上级只说了一句话，接下来怎么干？
3. 完成线：做到什么程度才算完成？
4. 没把握的任务，怎样争取支持？
5. 还没做完，要不要先给对方看？

### 第5章　计划：复杂任务，怎样安排才好执行

1. 分而治之：大任务怎么拆才好执行？
2. 任务之间有依赖，先后顺序怎么安排？
3. 计划会变，怎样提前安排检查和验证？
4. 时间不够，怎样协商范围、人手和交付安排？

### 第6章　执行：遇到卡点和风险，怎样把工作往前推进

1. 被别人卡住进度，除了等还能做什么？
2. 发现风险，越早说出来越有办法
3. 向上求援：哪些事该找上级，怎么开口？
4. “事情到我为止”：让问题有人管、有下文
5. 防范风险，别靠侥幸，也别绕过规范

### 第7章　靠谱：把工作做得有始有终

1. 接到事情有回应，结束以后有交代
2. 进度汇报：别等别人来问“怎么样了”
3. 承诺交付时间，怎样估算才靠谱？
4. 工作做完了，交付前还要检查什么？
5. 请假前，怎样交接才能让人放心？

## 第三篇｜与人合作：沟通、协作与职业关系

### 第8章　沟通：把话说清楚，也把对方听明白

1. 向人求助，怎样把问题说清楚？
2. 听懂诉求：对方到底在意什么？
3. 有不同意见，怎样表达才有说服力？
4. 同样的话，怎么说才不容易变成对抗？

### 第9章　预期管理：与上级合作，先谈清彼此的要求

1. 了解上级的目标，也说清自己的诉求
2. 上级说“做好一点”，怎样问清评价标准？
3. 对工作有预期的，不止直属上级
4. 面对“画饼”，怎样判断机会靠不靠谱？
5. 目标变了、上级换了，哪些约定要重新沟通？

### 第10章　协作：没有管理职权，怎样推动跨团队工作

1. 跨团队协作，怎样找全所有参与者？
2. 职责灰色地带的事，谁来负责？
3. 用指南和共同记录，减少反复沟通
4. 组织能力，怎样从日常协作中磨炼出来？

### 第11章　边界：积极主动，也要懂得说“不”

1. 主动做事，为什么不等于什么工作都接？
2. 面对临时插入的工作，原来的工作怎么办？
3. 不该接、接不下来的事，怎样说“不”？
4. 守住工作承诺，也尊重彼此的做事方式

### 第12章　职业关系：与同事相处，怎样把握分寸

1. 看不惯一个人，还能好好共事吗？
2. 走出熟人圈，认识不同岗位和领域的人
3. 受过的帮助，怎样回应才有诚意？
4. 和上级走得近，也要分清工作与私交
5. 性格内向，怎样融入团队？

## 第四篇｜管理自己：时间、注意力、精力与情绪

### 第13章　时间管理：每天都很忙，怎样让重要的事有进展

1. 一周忙下来，时间都花到哪里去了？
2. “假努力”：做的事和真正的目标有关吗？
3. 时间四象限：重要和紧急，怎样分先后？
4. 每日三件事：给长期目标安排今天的行动

### 第14章　注意力：总被打断、容易走神，怎样保持专注

1. 脑子里总惦记别的事，先把它们记下来
2. 抉择点：继续做，还是换一件事？
3. 注意力专区：怎样专注，又不把自己绷得太紧？
4. 消息、会议不断，怎样留出专注时间？

### 第15章　精力：怎样的努力值得付出

1. “卷”得值不值，要看收益和代价
2. 产出上不去，是方法不对，还是精力不够？
3. 内耗式努力：别把精力花在反复纠结上
4. 按精力安排工作，也给休息留出时间
5. 休息也缓不过来，该重新审视哪些工作安排？

### 第16章　情绪：面对批评、委屈和比较，保留自己的判断

1. 情绪上来时，先把事实和自己的解释分开
2. 情绪劳动：忍住了火气，为什么会觉得很累？
3. 觉得什么都做不了，怎样找回控制感？
4. “核心我”：听取反馈，也守住自己的目标和底线
5. 这是工作反馈，还是职场 PUA？

## 第五篇｜持续成长：学习、复盘与职业选择

### 第17章　学习：怎样学，才能在工作中用得上

1. 眼前要用的和长期要学的，怎样一起安排？
2. 知识债务：借来的办法用上了，欠的功课怎么补？
3. 从消费者到生产者：用成果检验学会了没有
4. 找导师、找同伴，怎样获得有用的反馈？
5. 留下作品和反馈，别让每次学习都从零开始

### 第18章　复盘：把经历变成经验

1. 工作三年，为什么可能只有一年的经验？
2. 复盘先还原事实，再看当时的判断
3. 找到直接原因之后，还要往下追问什么？
4. 一次经历得出的经验，换个场景还适用吗？
5. 复盘之后，把经验整理成样板、标准和反馈

### 第19章　职业竞争力：怎样形成自己的优势

1. 补短板还是练长板，精力该花在哪里？
2. 资本与成本：工作做完了，还带来了什么价值？
3. 附加价值：同样能做这份工作，别人为什么选我？
4. 哪些短板要自己补，哪些可以借力？
5. 换个岗位，哪些能力仍然带得走？

### 第20章　绩效与晋升：看懂要求，做好准备

1. 完成任务、创造贡献、提升能力，不是一回事
2. 绩效自评，怎样写清自己的贡献？
3. 绩效沟通，除了听结果还该谈什么？
4. 想尝试管理，从做上级的“备份者”开始
5. 能力和绩效都不错，为什么还没轮到晋升？

### 第21章　职业选择：留下、换岗，还是离开

1. 现在这份工作，还值得继续投入吗？
2. 零基思维：重新选一次，还会选现在的工作吗？
3. 换工作，除了薪酬还该比较什么？
4. 第二曲线：怎样在不辞职时尝试新方向？
5. 职业安全感：为变化准备好能力和支持

## 结语｜能把事情做成，也能为自己作主
