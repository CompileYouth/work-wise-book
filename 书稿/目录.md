# 学会工作：从学生到职业人的前三年

> 暂定书名 · 目录修订稿
>
> 面向工作 0—3 年的职场新人，围绕五个问题展开：如何理解职场与自己的角色，如何把事情做成，如何与人合作相处，如何管理自己，以及如何积累能力、经营职业发展。

## 序言｜毕业之后，还要重新学习什么

- 为什么认真、努力、成绩好，仍可能在工作中感到无措
- 从一次次具体的工作经历中，练习职业人的判断和行动
- 如何使用这本书：顺着成长路径读，也可以带着手头的问题读

## 第一篇｜看懂职场：理解合作规则，找到自己的位置

### 第1章　毕业了，为什么过去的好方法不灵了

1. 把自己的事做完，还不够吗？
2. 什么都自己来，才算有能力吗？
3. 不会就问，还不对吗？
4. 上级会像老师一样带着我吗？
5. 上级只安排工作，谁来安排我的成长？

### 第2章　进入新团队，别等着有人来带

1. 认识公司、部门与团队：画出自己的工作地图
2. 与上级的第一次沟通：确认职责、目标和阶段预期
3. 与导师的第一次沟通：了解流程、规范和协作对象
4. 跟每位同事吃顿简餐：在闲聊里熟悉团队和业务
5. 暂时没人带你时：主动找资料、找人、找反馈

### 第3章　用“老板心态”，理解手上工作的价值

1. 从一张停水通知说起：做了动作，是否实现了目的
2. 把工作当作一项服务：为谁交付，解决什么问题
3. 培养工作 sense：从业务目标和指标理解任务的意义
4. 对结果负责，也算清时间、成本与质量之间的取舍
5. 从真实需求出发，找到职责内值得主动改进的地方

## 第二篇｜把事情做成：建立让人放心的交付习惯

### 第4章　接到任务，先把“做成什么样”说清楚

1. 明明听懂了，怎么还是做错了？
2. 上级只说了一句话，接下来怎么干？
3. 到底做到什么程度，才算完成？
4. 没把握的任务，怎样争取支持？
5. 还没做完，要不要先给对方看？

### 第5章　面对复杂任务，做一份能执行的计划

1. 把大任务拆成可以估算、执行和检查的小步骤
2. 找到关键依赖：哪些事情必须先做，哪些可以并行
3. 设置里程碑，为未知问题留出验证和调整的空间
4. 时间不够时，协商范围、资源与交付顺序

### 第6章　遇到卡点，学会推进、求援与控制风险

1. 找出真正的阻塞点，同时推进不受影响的部分
2. 尽早暴露风险，说明影响、已做的尝试与可选方案
3. 何时向上求援：需要决策、资源、协调还是建议
4. “事情到我为止”：持续跟进问题，明确责任与权限
5. 克服侥幸心理，理解规范的作用，推动失效流程改进

### 第7章　工作有始有终，靠谱才会成为你的口碑

1. 接到事情有回应，结束以后有交代
2. 让工作可见：及时同步进度、阻塞与下一步
3. 低承诺、高兑现：诚实估算，留出余量，变化时及时重谈
4. 按标准验收交付，说明实际结果与遗留事项
5. 请假、调岗与任务交接：让接手的人能继续往下做

## 第三篇｜与人合作：做成事，也建立长久的职业关系

### 第8章　与上级合作，从对齐预期开始

1. 理解上级关心的目标，也让对方了解你的诉求
2. 把“做好一点”“做个示范”变成明确且可实现的标准
3. 识别不同层级与协作方的预期，约定信息同步方式
4. 面对“画饼”，问清条件、支持、决策者与时间节点
5. 目标变化或更换上级后，重新确认方向、标准与调整安排

### 第9章　把话说清楚，也把对方听明白

1. 提问前，整理背景、自己的判断和具体卡点
2. 听懂要求背后的诉求，减少各说各话
3. 表达不同意见：拿出依据、取舍和备选方案
4. 用开放的表达与合适的沟通方式，减少误解和对抗

### 第10章　没有管理职权，也能推动跨团队协作

1. 找齐协作方，明确负责人、执行顺序与相互依赖
2. 看见职责之间的空隙，推动形成分工共识
3. 通过指南、样例和共同记录，降低大家的协作成本
4. 练习组织能力：把人的协作、工具的使用和反馈串成流程

### 第11章　积极主动，也要有自己的边界

1. 分清有效的主动与盲目接活
2. 面对临时插单，用重要性、紧急性和资源讨论优先级
3. 合理说“不”：说明约束，提出替代安排
4. 对已有承诺负责，也尊重彼此不同的工作方式

### 第12章　与同事相处，建立有分寸的职业关系

1. 与看不惯的人共事：把分歧留在事情上，避免长期较劲
2. 走出熟人圈：通过日常交流认识不同岗位和领域的人
3. 对帮助有回应：真诚表达感谢，也分享自己的经验与支持
4. 与上级亲近时，仍看清角色差异和私人信息的边界
5. 内向也能融入团队：找到适合自己的联结与归属感

## 第四篇｜管理自己：让努力有重点，也能持续下去

### 第13章　每天都很忙，怎样让重要的事真正往前走

1. 盘点时间去向：分清工作成果与忙碌带来的充实感
2. 识别“假努力”：回到行动背后的真实目标
3. 用时间四象限判断优先级，为重要但不紧急的事留位置
4. 把长期目标拆进“每日三件事”，定期检查是否需要调整

### 第14章　保护注意力，在中断中恢复工作的节奏

1. 区分外部打断与内部走神，记录尚未处理的念头和任务
2. 抓住“抉择点”：有意识地决定继续、暂停还是切换
3. 觉察松散与紧绷，找到适合自己的“注意力专区”
4. 用专注时段和沟通约定管理消息、会议与紧急响应

### 第15章　精力有限，判断怎样的努力值得付出

1. “有效的卷”与“无效的卷”：看目标、收益，也看个人代价
2. 时间排满却没有产出：区分精力不足与方法不当
3. 减少内耗式努力：用明确的选择和习惯降低反复纠结
4. 按精力起伏安排任务，把恢复和休息纳入计划
5. 持续疲惫时，重新审视工作负荷、支持条件与环境

### 第16章　面对批评、委屈和比较，保留自己的判断

1. 区分发生的事实、自己的解释与随之而来的情绪
2. 看见情绪劳动的消耗，表达感受与需要
3. 重建控制感：把无措拆成能行动、能协商、需支持的选项
4. 从批评中提取反馈，以“核心我”辨认自己的目标和底线
5. 识别职场“PUA”：区分具体反馈与持续贬低、操控，选择应对方式

## 第五篇｜持续成长：积累自己的能力，经营自己的职业

### 第17章　重新学会学习：从知识消费者到生产者

1. 为眼前问题学习，也为长期方向安排系统学习
2. 知识债务：借助外力向前走，记下需要补足的理解与能力
3. 用解决问题、讲解和作品检验学习，形成“消费—生产—反馈”的循环
4. 找到愿意提供具体反馈的导师与同伴
5. 保存有用的作品和反馈，让一次学习服务下一次实践

### 第18章　学会复盘，把经历变成可复用的经验

1. 工作三年，怎样避免只是在重复第一年的经验
2. 还原目标、过程和结果，识别关键判断与偏差
3. 从现象追到原因，进一步看见流程与协作中的问题
4. 写下适用条件与下次的改法，在新实践中验证经验
5. 把经验整理成样板、标准与反馈，供以后复用

### 第19章　经营自己的职业价值：长板、短板与附加价值

1. 短桶与长桶：守住岗位基本要求，在分工中发展长板
2. 用“资本与成本”审视贡献：我能持续带来哪些价值
3. 走出同质化竞争：把优势变成对他人有用的附加价值
4. 处置短板：选择亲自掌握、借助工具或寻求协作
5. 在真实成果中验证优势，积累离开当前岗位也带得走的能力

### 第20章　面对绩效与晋升，学会评价自己的成长

1. 弄清岗位要求，区分完成任务、创造贡献和能力提升
2. 平时积累成果证据，写清自己的判断、行动与实际作用
3. 借绩效沟通确认优势、差距与下一阶段的成长机会
4. 有意走向管理时，从部分业务的“备份者”练习承担更大责任
5. 持续了解组织规则：工作年限、能力成长与晋升机会各有条件

### 第21章　为下一步留出选择，走出自己的职业道路

1. 定期盘点：当前工作还能提供哪些能力、机会与回报
2. 用零基思维重新比较选项，同时算清现实的转换成本
3. 留下、换岗或离开，结合团队、上级、收入和生活需要取舍
4. 留任期间探索第二曲线，以小规模尝试检验新方向
5. 建立应对变化的能力与支持，保留自己的节奏和选择空间

## 结语｜成为一个能做成事，也能为自己作主的人
