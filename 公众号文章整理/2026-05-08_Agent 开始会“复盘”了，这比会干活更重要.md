## 正文

> TL;DR
>
> Agent 真正的分水岭，正在从“能不能把任务做出来”，转向“能不能从过去的任务里变得更稳”。会执行当然重要，但会整理记忆、吸收反馈、减少重复错误，才更接近一个能长期协作的系统。

最近 Anthropic 给 Claude Managed Agents 加了一个新能力，叫 dreaming。

这个名字很容易让人想歪，好像 AI 也开始像人一样做梦了。

但真正值得关注的，不是“做梦”这个词，而是它背后的变化：**Agent 开始被设计成可以回顾过去、整理记忆、发现模式，并改进下一次表现。**

这件事比“会干活”更重要。

因为一个 Agent 偶尔把任务做出来，并不稀奇。

真正难的是，它能不能在长期使用中越来越稳。

## 过去的经验，主要靠人来补

以前我们调教 Agent，很多时候靠的是人。

它这次犯了一个错误，我们就补一条规则。

它某个流程跑偏了，我们就把流程写得更清楚。

它输出不稳定，我们就加一层检查。

这些做法当然有用。

但问题是，经验主要还是人在外面帮它整理。

Agent 自己未必知道，哪些错误反复出现，哪些偏好应该保留，哪些记忆已经过时。

所以很多时候，我们说是在“训练 Agent”，其实是在训练它外面的那套规则、文档和流程。

## dreaming 的重点不是做梦，而是整理记忆

Anthropic 官方文档里对 dreaming 的解释很明确：它会读取已有 memory store 和过去的 session transcripts，然后生成一个重新整理过的 memory store。这个新 memory 会合并重复内容，替换过时或矛盾的信息，并提炼新的 insight。原始 memory 不会被修改，开发者可以先审查输出，不满意也可以丢弃。

换句话说，dreaming 不是让 AI 像人一样睡觉做梦。

它更像是在任务和任务之间做一次系统复盘。

Agent 工作时会不断写入 memory，但这些写入往往是局部的、零散的。时间一长，memory 里就可能堆满重复、过期、甚至互相矛盾的信息。Anthropic 的 memory 文档也提到，memory store 是跨 session 保留信息的机制，可以记录用户偏好、项目约定、过去错误和领域上下文。

如果只有 memory，没有整理，记忆会越来越杂。

dreaming 做的，就是把这些杂乱记忆重新清理一遍。

## 真正成熟的 Agent，不能每次都从零开始

很多人用 AI 时，最烦的不是它这次做错了。

而是同样的问题说过很多遍，下次还是可能再犯。

同样的偏好反复交代，同样的错误反复纠正，同样的流程反复带一遍。

这就是没有长期连续性的痛苦。

如果一个 Agent 每次都像第一次认识你，它再聪明，也只是一个高级临时工。

长期协作需要的不是一次惊艳，而是下一次更稳。

它要知道哪些反馈值得留下，哪些错误反复出现，哪些经验已经不适用了。

这也是 dreaming 指向的真正趋势：

**Agent 的竞争，正在从“能不能完成任务”，转向“能不能从过去的任务里变得更稳”。**

## 复盘能力会成为新的分水岭

以前我们判断一个 Agent 强不强，主要看它能不能执行。

能不能写代码，能不能查资料，能不能改文件，能不能调用工具。

这些当然重要。

但当越来越多 Agent 都能执行任务之后，新的差距会出现在别的地方。

它有没有记忆？

它会不会整理记忆？

它能不能把一次次纠偏，变成下一次更稳的表现？

执行能力决定 Agent 能不能干活。

复盘能力决定 Agent 能不能长期托付。

一个不会复盘的 Agent，就算这次做得不错，下次依然可能不稳。

一个能复盘的 Agent，才有机会减少重复错误，逐渐接近一个真正能长期协作的系统。

## 不要只盯着规则

这件事对我们使用 Agent 也有提醒。

过去调教 Agent，很多时候是人替它记经验。

错一次，人补一条规则。

流程跑偏，人再写清楚一点。

结果不稳，人再加一道检查。

这当然有用，但它也说明 Agent 本身还不够“会长记性”。

dreaming 真正指向的，是让 Agent 在任务之间自己整理经验：哪些错误反复出现，哪些偏好应该保留，哪些记忆需要清理。

这才是长期协作的关键。

否则它只是一个每次都要重新带的执行者。

## Agent 的下一步，是越用越稳

所以我并不觉得 dreaming 这个词本身多重要。

甚至这个词有点容易误导人。

真正重要的是，它说明顶级 Agent 产品开始把“复盘”做进系统里。

过去的 Agent 更像执行器。

你下命令，它去做。

未来的 Agent 会越来越像长期协作者。

它不只是完成任务，还会整理过去的任务，吸收反馈，更新记忆，改进下一次表现。

第一次惊艳并不难。

长期稳定才难。

一个成熟的 Agent，不只是更能干，而是越用越稳。
